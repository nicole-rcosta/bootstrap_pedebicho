# 🐾 Pé de Bicho

O **Pé de Bicho** é uma plataforma web dedicada à causa animal, focada em facilitar o registro de pets encontrados em situação de rua e promover a adoção responsável. O projeto combina um visual moderno e acolhedor com uma interface intuitiva.

## 🎨 Identidade Visual

O projeto utiliza uma paleta de cores cuidadosamente selecionada para transmitir confiança e energia:

* **Laranja (#F2994A):** Cor principal para ações e headers.
* **Azul (#1D428A):** Utilizado para contraste na marca e elementos de seriedade.
* **Bege (#F2E9DB):** Fundo suave para uma leitura confortável.

## 🚀 Funcionalidades

* **Página Inicial (Index):** Exibição de pets disponíveis em um grid dinâmico de 5 colunas.
* **Hero Section:** Carrossel interativo com banners promocionais.
* **Registro de Pets:** Formulário estilizado em "caixa" (card) para cadastro de novos animais.
* **Design Responsivo:** Adaptável para dispositivos móveis, tablets e desktops utilizando o sistema de grid do Bootstrap 5.
* **Alertas Inteligentes:** Integração com SweetAlert2 para feedbacks visuais modernos.

## 🛠️ Tecnologias Utilizadas

* **HTML5:** Estrutura semântica das páginas.
* **CSS3:** Estilização personalizada e layouts flexíveis.
* **Bootstrap 5.3.3:** Framework para agilidade no desenvolvimento e responsividade.
* **Bootstrap Icons:** Biblioteca de ícones vetoriais.
* **SweetAlert2:** Janelas de diálogo e alertas personalizados.
* **JavaScript:** Lógica de interação e envio de formulários.

## ⚙️ Como rodar o projeto

1. Faça o download ou clone este repositório.
2. Certifique-se de manter a estrutura de pastas conforme listado acima.
3. Abra o arquivo `index.html` em qualquer navegador moderno.
4. Para uma melhor experiência de desenvolvimento, utilize a extensão **Live Server** no VS Code.
